研究愿景 Scope 图设计说明

这是为研究者本人设计的一张研究范围总览图，内容完全依据本次用户提供的研究愿景。当前交付阶段为三方向真实初稿，尚未选定最终方向。图的任务是让学术同行、潜在合作者、评审或学生在短时间内理解研究对象、总体目标、双向定位与六个研究方向之间的关系。初始用途假设为学术汇报和研究愿景介绍，也适合后续适配个人主页；已询问用户具体用途与视觉参考，如有补充则同步修订。图以中文为主，保留英文术语，信息清晰优先于装饰。

统一输出为 1920 × 1080 像素横版单图，每方向一份自包含 HTML/CSS 文件，可使用 SVG 绘制真正承担关系表达的线条、箭头和框架，不使用 SVG 生成物品或人物插画。所有文本保持真实可选取，截图导出 PNG。单文件离线可打开，无 CDN、无远程字体、无 React 依赖。根画布使用 id="scope"，固定 1920 × 1080，视口变小时通过 JS 等比缩放，禁止裁切。页面打印支持相同画布。不要把设计说明、版本编号、方向标签或工作室名称放进图内。正文建议 24 至 30 px，研究方向标题 28 至 34 px，英文与说明不小于 19 px，最高标题 48 至 60 px，保证投屏与缩略图仍有层级。正文对比度至少 4.5:1。

图内总标题必须准确保留：面向智能体时代的可信软件交互与智能质量保障。允许分成两行，其中“可信软件交互与智能质量保障”视觉优先。双向定位必须完整且显著：通过智能体提升软件质量；通过软件工程保障智能体质量。可以用两个方向的箭头、上下反馈关系、左右双向结构等表达，不能让一方成为另一方的附属，也不能暗示六个研究方向被互斥地划分到两边。

四个定位要素需要明确呈现：特色研究对象为交互 Interaction；核心目标为可信 Trustworthy；约束为安全可控 Security & Controllability；关键能力为智能执行 Intelligent Execution。应通过位置、框架或连接关系体现功能，避免将四个概念当成四个平级研究课题。人与智能体、智能体与软件之间的交互可以作为研究对象的直观解释，但不得声称这些边界穷尽整个研究领域。

六个研究方向均必须出现完整中文标题和对应英文术语，用户原始编号可作标识，但不表示执行次序。每个方向提供一条精简解释，严格保留原意：

01 软件交互质量保障 / Software Interaction Quality Assurance。关注交互过程与结果的正确性、可靠性，以及用户意图和业务约束的满足。可用简述“过程与结果正确可靠，满足用户意图与业务约束”。

02 智能体软件的安全与可控性 / Security & Controllability。关注行为边界、权限约束、风险控制，以及必要的人类监督与接管。可用简述“行为边界 · 权限约束 · 风险控制 · 人类监督与接管”。可以以贯穿的外框呈现，仍须清楚标识其研究方向身份，不能压缩为一条几乎不可见的脚注。

03 意图驱动的智能任务执行 / Intent-Driven Intelligent Task Execution。研究意图理解、任务规划、交互执行、结果验证、失败恢复。可以用过程链表达并将失败恢复接回执行或规划，但不能把这五步当成六个研究方向的整体顺序。

04 交互行为验证与运行时保障 / Interaction Verification and Runtime Assurance。关注行为检查、异常检测与动态干预，让自动化可验证、可约束。可以与执行过程相连接，不应和结果验证混为一项。

05 智能体软件质量工程 / Quality Engineering for Agent-Integrated Software。以软件工程方法支持智能体的测试、评估、诊断与改进，提升可靠性、鲁棒性和适应性。

06 人机协同的软件质量提升 / Human–Agent Collaborative Software Quality Improvement。结合人的知识、判断与反馈和智能体的分析、执行能力，支持软件缺陷发现、修复与持续改进。不能把人的作用缩减成安全接管，人参与知识、判断与质量改进同样重要。

视觉气质为清楚、严谨、有辨识度、适合学术沟通。读取现有主页后得到可沿用的色彩参照：白底、深灰 #333333、学术蓝 #2f617c、链接蓝 #345b73、浅灰 #f8f9fa。但这些不是锁定品牌，三方向允许有经论证的不同色温，需避免紫渐变、霓虹发光、装饰图标、六张等权卡片堆叠，以及把概念关系复杂化的密集交叉箭头。中文可用本地 PingFang SC、Songti SC；英文可用本地 Avenir Next、Georgia、Trebuchet MS，避免联网取字体。

图片前置判断：本图为纯研究概念与关系图，真实照片、人物、产品图都不构成必要内容，因此不取图、不生图、不使用占位素材。图内无第三方品牌或产品，没有 logo 资产需求。

视觉母题必须来自内容自身：双向质量提升与受约束的交互执行。各方向可自行选择结构，但必须用布局清楚表达共同目标、交互对象、执行能力、约束保障、持续改进之间的联系。不要虚构指标、论文成果、定量比例、成熟度层级或评价结论。三个方向互相独立，只读取本说明及自身参照，不读取别的方向成果。
