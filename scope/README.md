These are the current English research-scope diagrams. The final layout has not been selected. Open index.html to compare the three alternatives. Each figure has a self-contained HTML preview, an editable SVG source, and a 2640 × 1560 PNG. The SVG canvas is 1320 × 780. Earlier drafts are available in Git history.

The design contract is a concise software-engineering / AI paper or proposal figure: English only, research-direction titles without explanatory descriptions, a consistent set of line icons, white background, restrained blue and teal, and a small number of meaningful relationships. Each research direction is enclosed in a rounded rectangle, with tight spacing and restrained card fills. Goal and constraint labels are embedded in their research cards; the execution card contains both the capability title and the Human–Agent–Software interaction object. Reciprocal positioning labels belong to actual card-to-card connector paths, so they form part of the research structure. The figure must distinguish the reciprocal research positioning, interaction object, trustworthiness goal, security constraint, execution capability, and relationships among all six directions.

The reciprocal positioning is Agents for Software Quality and Software Engineering for Agent Quality. Human–Agent–Software interaction is the shared object. Software Interaction Quality Assurance supports trustworthiness; Security & Controllability constrains the interaction and execution system; Intent-Driven Intelligent Task Execution provides the capability; Interaction Verification and Runtime Assurance guards behavior during execution; Quality Engineering for Agent-Integrated Software feeds improvement into the system; Human–Agent Collaborative Software Quality Improvement joins human knowledge and feedback with agent capabilities. These descriptions guide the diagram semantics and must not be added as body text inside the figure.

Lucide icon geometry is embedded in every SVG and HTML. The icon license is embedded in their metadata and retained in LUCIDE-LICENSE; no separate icon library or network dependency is required. Keep this directory limited to current previews, editable sources, exports, necessary licenses, and concise design context.
