The six research directions are peers. Each figure must contain exactly six equally sized rounded research cards with the same title font, icon size, fill, and border weight. Never nest one research direction inside another or make security, quality assurance, or execution a parent direction. Use a compact technical paper/proposal style: English only, direction titles without explanations, consistent line icons, restrained colors, and clear connectors. Every arrow between research cards must have a nearby one- or two-word English relationship label and an unambiguous source and target. These links express complementary contributions, not a chronological process or hierarchy.

The overall framework shares the reciprocal focus Agents for Software Quality and Software Engineering for Agent Quality, the object Software Interaction, the goal Trustworthiness, the constraint Security & Control, and the capability Intelligent Execution. Shared context belongs at framework level and must not elevate any research direction above the other five.
